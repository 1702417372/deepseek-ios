# 主页改版计划（对齐官方 DeepSeek App 首页，2026-11-23 13:50 记录）

参考图：docs/reference/official-home.jpg

## 目标：首页（空会话状态）按官方 App 重做

1. **顶栏**
   - 左侧：圆形悬浮菜单按钮（≡，白色圆底 + 轻阴影）
   - 右侧：圆形「朗读开关」（speaker.slash / speaker.wave.2，对应自动朗读）+ 圆形「+ 新对话」
   - 不显示模型名（模型切换移到「+」菜单 / 设置里）

2. **欢迎区（居中、极简）**
   - 鲸鱼 Logo（AppLogo，约 64pt）
   - 一行文案：**欢迎回来，随时开始吧**
   - 去掉现在的副标题和 4 张建议卡（与官方一致）

3. **输入区（大圆角卡片，替代现在的多行小工具条）**
   - 占位文案：**发消息或按住说话**
   - 卡片内底部一行：**深度思考** pill（思考开关）+ **智能搜索** pill（联网开关）+ 弹性空隙 + **✕**（清空草稿/附件）+ **麦克风圆钮**（点按录音，长按说话）
   - 模型选择收进「+」菜单；附件仍显示在输入卡片上方一排缩略图
   - 发送按钮：有文字时替换麦克风位置为蓝色发送圆钮（与官方一致）

4. **底部三张功能卡（仅首页显示）**
   - 拍照 / 相册 / 文件，三张等宽圆角卡（图标 + 文字），分别触发相机、PhotosPicker、fileImporter
   - 与输入区之间留出间距

5. **保留**
   - 未配置 API Key 时，欢迎页顶部保留一条细提示条（否则无法使用）
   - 已有会话的聊天界面不变（顶栏仍显示标题/模型，输入区可沿用新版大卡片）

## 实现落点
- Views/WelcomeView.swift：改成极简欢迎（logo + 文案 + 三张功能卡），新增 onCamera / onAlbum / onFile 回调
- Views/ChatScreen.swift：顶栏按状态区分（首页 vs 会话中）；首页隐藏建议卡
- Views/ComposerBar.swift：改成大卡片布局；深度思考/智能搜索 pill 下移；新增清空按钮；自动朗读开关上移顶栏
- 相机/相册/文件回调复用现有 ComposerBar 逻辑，或把三个动作提到 ChatScreen 统一管理
- 改完走 GitHub Actions 编译 + 模拟器截图，版本 1.5
